Disabled jobs stay in the Croniqfile but never fire. Useful during incident triage when you want the config in source control but don't want triggers to enqueue.

Runner command

Shares one budget with every other job naming the same group. Needs a matching concurrency_group <name> { max_concurrent N } block in your Croniqfile — an undefined name is a config error.

run_on_register — also fires the job when croniq first sees it and whenever its definition changes, for work that has to happen at deploy time and not only on schedule. Not on every restart or reload.
