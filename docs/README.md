# Croniq Documentation (Repo View)

The rendered homepage for these docs lives at [`docs/index.md`](./index.md). Use that file (and the VitePress dev server) for content changes.

Quick links:

- [`/introduction/`](./introduction/) – onboarding and configuration guides.
- [`/guides/`](./guides/) – auth, policies, triggers, handler patterns.
- [`/ops/`](./ops/) – troubleshooting and operations.

```cmd
cd docs
npm install
npm run docs:dev
```
