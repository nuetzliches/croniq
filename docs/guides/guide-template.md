# Feature Guide Template

Use this template when authoring or refreshing guides so readers see consistent structure across features.

## Overview

What the feature does, who it is for, and the key behavior or scope rules.

## API Surface

List the primary endpoints or SDK entry points (include paths and required parameters).

## Configuration

Document the required and optional configuration keys. Include a minimal example.

## Security

Describe auth scopes, signature requirements, or access constraints.

## Operations & Monitoring

Explain telemetry, retention, and operational checks.

## Examples

Provide one or two end-to-end snippets (curl, PowerShell, or C#).

## Troubleshooting

List common errors and suggested fixes.

## Related Guides

Link to adjacent guides or deep-dive docs.
